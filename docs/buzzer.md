# ピットの警報音（USBシリアル）

仕様書「回線が止まったとき」：critのときに、回線が要らない音をピットで鳴らす。手持ちのSTM32にブザーを付け、USBシリアル（CDC-ACM、例：`/dev/ttyACM0`）で鳴らす。ファームは対象外で、PCから送る内容だけをここに決める。

## PCが送るもの

| 送るバイト | いつ | 相手にしてほしいこと |
| --- | --- | --- |
| `0x43`（ASCIIの `C`） | critの警報の発生と追加のたび | 目立つ鳴らし方（例：0.2秒鳴る・0.2秒止まるを5回） |

- 1バイトだけ送り、返事は待たない。相手がいない・開けないときは記録だけ残して監視を続ける。
- 通信の設定：115200bps、8N1、フロー制御なし（`config.json` の `notify.buzzer_baud` で変えられる）。CDC-ACMでは速度は実質関係ない。
- 同じcritでも、通知の抑制（30秒以内の再通知なし）に合わせて鳴る。鳴らす長さは相手側で決める。
- ほかのバイトは今は送らない。相手は知らないバイトを無視する作りにしておく。

## 設定

`config.json` の `notify.buzzer_device` にデバイスのパスを書く（例：`"/dev/ttyACM0"`）。抜き差しで名前が変わる場合は `/dev/serial/by-id/...` を使う。

PCのユーザーが書き込めるように、ユーザーを `dialout` グループに入れておく（`deploy/setup.sh` で案内する）。

## 試し方（実機）

```bash
printf C > /dev/ttyACM0
```
